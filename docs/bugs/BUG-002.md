# BUG-002

## Bug Title

Background sound is white-noise-like, ignores volume, continues after stop, and overpowers speech after meanings.

## First Reported

2026-07-16

## User Report

The user reported a new audio/background-sound bug:

> 新的问题是：
> 1. rain 不像rain，是白噪音
> 2. 声音音量无法被控制
> 3. 点击停止之后还是在放白噪音
> 4. 拿 中文、japanese、food作为例子，播放完米饭 餐 之后白噪音就会变得特别大声，盖住声音，这种情况在选择别的combination也有复现

## Environment

- Project: LingoSleep

- Current branch at intake: `main`
- Frontend: React + Vite + TypeScript
- Audio stack: Web Speech API and Web Audio API generated background sounds
- Hosting: Cloudflare Pages
- Production URL: `https://lingosleep.pages.dev`
- Local timezone at intake: Asia/Singapore

## Reproduction Steps

Initial user-reported paths:

1. Select background sound `rain`.
2. Start playback and listen to the background sound.
3. Adjust voice/background volume controls.
4. Click Stop while background audio is playing.
5. Select native language Chinese, target language Japanese, topic Food.
6. Start playback and listen after the app says the meaning `米饭；餐`.
7. Repeat with other language/topic combinations.

## Expected Result

- `rain` should sound recognizably like rain, not generic white noise.
- Voice and background volume controls should affect the corresponding audio.
- Stop should immediately stop voice and background audio.
- Background audio should remain ducked or balanced around speech and should not suddenly become loud enough to cover the voice.

## Actual Result

- `rain` sounds like white noise.
- Audio volume cannot be controlled.
- After clicking Stop, white-noise-like background audio keeps playing.
- With Chinese + Japanese + Food, after `米饭；餐` is spoken, the background noise becomes very loud and covers the voice. Similar behavior is reproducible with other combinations.

## Severity

High. This affects the core audio playback experience and can continue unwanted sound after Stop.
